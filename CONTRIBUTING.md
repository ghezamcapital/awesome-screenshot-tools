# Contributing to Awesome Screenshot Tools

Thanks for your interest in contributing!

## Guidelines

- Search existing entries before adding a new one
- Add new items to the bottom of the relevant section
- Use the format: `[Name](URL) - Short description.`
- Keep descriptions concise (one line)
- The tool/service must be actively maintained
- No duplicates across sections

## Pull Request Process

1. Fork this repository
2. Add your entry to the appropriate section
3. Submit a pull request with a clear description

## Quality Standards

- The resource must be related to web screenshots, visual testing, or browser automation
- Commercial services should offer a free tier or trial
- Open source projects should have at least 10 stars or be actively maintained
